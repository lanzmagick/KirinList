# KirinList

An unofficial Android client for [AniList](https://anilist.co), forked from [AniHyou](https://github.com/axiel7/AniHyou-android).

[![Download APK](https://img.shields.io/badge/Download-APK-536DFE?style=for-the-badge&logo=android&logoColor=white)](https://github.com/lanzmagick/KirinList/releases)
[![Fork](https://img.shields.io/github/forks/lanzmagick/KirinList?style=for-the-badge&logo=github&label=Fork)](https://github.com/lanzmagick/KirinList/fork)
[![License](https://img.shields.io/badge/License-GPL--3.0-blue.svg?style=for-the-badge)](LICENSE)

Track your anime and manga, discover new titles, and manage your AniList lists. An AniList account is required for account features.

<details>
<summary><strong>Features</strong></summary>

- Anime and manga lists with progress tracking.
- Search, discovery, recommendations, and an airing calendar.
- Profiles, activity feeds, reviews, and notifications.
- Home screen widgets and a Wear OS companion app.

</details>

<details>
<summary><strong>Downloads</strong></summary>

<details>
<summary><strong>Build</strong></summary>

Open the project in Android Studio with JDK 17 and the required Android SDK, or build a FOSS debug APK with:

```sh
./gradlew :app:assembleFossDebug
```

</details>
